📖 Справка

ПЭДЫ 1–16 — запуск семпла. Свайп вниз — зажим (latch).

LOAD — загрузить аудио с устройства.

REC — запись с микрофона на свободный пад.

HOLD — держать ноту, пока не отпустишь режим.

SEQ — секвенсор: шаги для выбранного пада, PLAY.

CLEAR — очистить выбранный пад.

LOOP / REVERSE / GATE — режимы семпла на паде.

CHOP (PRO) — обрезка: TIME=START, LO-FI=END.

PITCH (PRO) — тон семпла (± полутона).

KEY — тональность (C–B). Долгое нажатие — назад.

Экран — волна пэда при нажатии; тап — смена визуала.

FILTER…VINYL — эффекты. VINYL — в PRO.

Крутилки — cutoff, reso, delay time, lo-fi.

💾 — экспорт текущего микса в WAV (скачивание).

Экран — тапни: вспышка / смена визуала.
